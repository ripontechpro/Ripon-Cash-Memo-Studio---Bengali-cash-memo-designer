# User Guide (Ripon Cash Memo Studio)
Shortcuts: Ctrl+1 Dashboard, Ctrl+2 New Memo, Ctrl+3 Templates, Ctrl+4 Customers, Ctrl+5 Products, Ctrl+6 History, Ctrl+7 Reports, Ctrl+8 Settings.

1. **First setup** — Settings: enter business name, address, phone, terms, thank-you text; choose your logo; Save.
2. **Products (optional)** — add products, or Import CSV (columns: name, sku, barcode, category, brand, purchase_price, selling_price, unit, stock). Set a low-stock level to track stock.
3. **New Cash Memo** — optional customer; type in the search box and press Enter to add a product, or add rows by hand. Discount cell accepts `10%` or `50`. Set VAT/TAX, delivery, paid, previous due. Totals update live. Save & Preview, then Print / Save PDF / Save Image.
4. **Template Studio** — New template; edit page size/orientation/margins/colours; add, move, delete or duplicate elements (text, line, rect, image, QR, barcode); edit table columns (add/remove/rename/resize/reorder). Preview uses sample data. Choose the template in the memo screen.
5. **Sales History** — search by number/customer/date/status/payment; reprint, duplicate, void (reason required), view audit trail. Issued memos are never silently overwritten.
6. **Reports** — choose a report and date range; export to CSV, Excel or PDF.
7. **Backup** — Settings: Backup now / Restore. Automatic backup runs when you close the app (last 14 kept).
QR codes encode only the memo number (a verification reference). No payment is ever claimed as verified.

## Ready-made Bengali templates
On first start the app installs 18 Bengali templates (Template Studio list). In "নতুন ক্যাশ মেমো" choose one in the template box (default: রিপন ক্লাসিক).
Blank numbered rows are printed so a memo can also be filled by hand. Edit any template in Template Studio: your shop info comes from Settings, so one
change in Settings updates every template. Duplicate a template before editing if you want to keep the original.

## ভাষা ও ফন্ট (Language & Font)
Settings -> "ভাষা ও ফন্ট":
- **অ্যাপের ভাষা** (বাংলা / English), **অ্যাপের ফন্ট**, **অ্যাপের লেখার আকার** (ছোট 100% / মাঝারি 115% / বড় 130% / অতি বড় 150%) — "এখনই রিস্টার্ট করুন" চাপলে কার্যকর হয়।
- **ডকুমেন্টের ভাষা** ও **ডকুমেন্টের ফন্ট** — মেমো/টেমপ্লেট প্রিন্টের জন্য; রিস্টার্ট লাগে না। একই ভাষা/ফন্ট প্রিভিউ উইন্ডোর উপরেও বদলানো যায় (প্রিভিউ, PDF, প্রিন্ট একই রকম হয়)।
- English বাছলে টেমপ্লেটের স্ট্যান্ডার্ড লেখা (কলামের নাম, ট্যাগ, নোট, মোট/ডিসকাউন্ট ইত্যাদি) ইংরেজিতে ছাপা হয়; আপনি নিজে যা লিখেছেন তা বদলায় না।
- লেখা ছোট লাগলে "অ্যাপের লেখার আকার" বাড়ান।
